# dsh-offwork-countdown

输入框下方的**下班倒计时**和一条**点一下归零的计时器**，外加一张可拖动的悬浮卡片。

## 三个位置

| 位置 | 显示什么 | 关掉「显示秒」后 |
|---|---|---|
| 悬浮卡片 | 大号倒计时 + 进度条 + 下班时间 | `01:27` |
| 用量栏 · 倒计时 | 距下班 / 距午饭 / 午休 / 已下班 | `距下班 01:27` |
| 用量栏 · 计时器 | 距上次喝水（文案可改），点一下归零 | `距上次喝水 01:27` |

## 设置

`设置 → 插件 → 下班倒计时`，简介下面那张卡片。三个位置各自有**开关**和**显示秒**。

## 行为

- 周一到周五算工作日；下班时间不晚于上班时间时，按跨夜班次处理。
- 午休时段倒计时改数「距午休结束」，进度条停在那一段（午休不算工时）。
- 计时器的基准是「当天上班时间」和「上次点击」里更晚的那个，所以隔夜不会累加。
- 进度条只走灰阶，不随状态换色，也不会闪。
